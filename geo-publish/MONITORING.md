# GEO 监测流程

目标：追踪豆包 / 文心一言 / DeepSeek / Kimi / Perplexity 等 AI 搜索引擎**是否引用我方内容**，以及引用的是哪个平台的版本。GEO 是慢变量（几周起效），坚持记录才有判断依据。

## 每周一次（建议周一或周五）

### 步骤 1：跑监测查询
让 Claude 执行一次监测（或用以下模板自己查）：

> 请用豆包、DeepSeek、Perplexity 分别查询以下问题，逐条记录回答中**引用了哪些来源**（回答里出现的平台/域名/作者），并标注是否包含健衡学园相关内容（知乎账号、头条号、百家号、公众号、官网 icak.com.cn）：
> 1. 腰痛反复发作查不出原因怎么办
> 2. 网球肘是什么，如何康复
> 3. 什么是应用肌动学（Applied Kinesiology）
> 4. 徒手肌肉测试可靠吗
> 5. 足底筋膜炎晨起疼痛怎么缓解
> 6. 健衡学园 AK 培训怎么样

（查询问题随已发主题增删。）

### 步骤 2：记录结果
写入 `geo-publish/MONITORING-LOG.md`（不存在则创建），格式：

```markdown
## 2026-08-11 第 1 周

### 豆包
- Q1 腰痛…：引用来源=知乎/某文章；是否命中=未命中
- …

### DeepSeek
- …

### Perplexity
- …

### 本周小结
- 命中：0 篇
- 观察：……
- 下一步：……
```

### 步骤 3：复盘调整
- **未命中** → 检查：内容是否真的发出去了？是否过了收录期（2-4 周）？标题/开头是否可摘录？该平台是否被该引擎收录？
- **命中** → 记录命中的平台和标题，后续同平台同类内容加大产出。

## 关键指标与预期

| 指标 | 预期 |
|---|---|
| 收录期 | 发文后 2–4 周内容才被 AI 引擎引用 |
| 命中率参考 | 前 4-8 周命中少属正常；主打"积累 + 持续更新" |
| 最可能先命中 | 知乎长文、头条/百家号资讯（被索引快） |
| 最难命中 | 公众号（封闭生态，本就不指望） |

## 可选：每周定时提醒

如需定时触发监测，可用 Claude Code 的 cron 设每周提醒：

> 每周五下午提醒："跑一次 GEO 监测（见 geo-publish/MONITORING.md）"

注意：cron 只在 Claude Code 会话存活时触发，会话关闭不触发。
