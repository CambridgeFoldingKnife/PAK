# GEO 批量发文工作流 · 使用手册

本目录是健衡学园 GEO 批量发文工作流的**输出区**与**操作手册**。

- Skill（内容工厂）：`.claude/skills/geo-publish/`（生成发布包）
- 发布包输出：`geo-publish/<日期>/<主题>/`（本目录下）
- 监测：见 `MONITORING.md`

## 快速开始

```
1. 让 Claude 跑：/geo-publish 腰痛
   （或批跑：/geo-publish 腰痛 网球肘 偏头痛）
2. 审核：看 geo-publish/<日期>/腰痛/ 里的 CHECKLIST.md，确认各平台稿达标
3. 发布：按下方各平台方式发布，逐项打勾
4. 记录：发完把 MANIFEST.md 里的状态改成"已发布"
```

## 各平台发布方式

| 平台 | 发布方式 | 自动化 | 前置准备 |
|---|---|---|---|
| 微信公众号 | 调 `baoyu-post-to-wechat` skill，API 推草稿，人工过目后群发 | 自动 | 公众号 API 凭据（该 skill 已配置） |
| 知乎 | 手动粘贴 `知乎.md` 到问题/文章编辑器 | 手动 | 知乎账号 |
| 小红书 | 按 `小红书-图文脚本.md` 做图 + 粘正文 + 加话题 | 手动 | 小红书创作号（健康类建议企业认证） |
| 今日头条 | 手动粘贴 `头条·百家号.md` 到创作者中心 | 手动 | 头条号 |
| 百家号 | 开放 API（需资质）→ 后接自动 | 半自动 | 百家号开放平台资质 |

## 周更节奏建议

- **每周 1–2 个主题 × 全平台** = 每个主题出 5 个版本。
- 理由：AI 引擎偏好持续更新；每周 1-2 主题的人力可控，质量闸门可守住。
- 主题优先用 `references/topics.md` 的首发优先级（腰痛→网球肘→足底筋膜炎→偏头痛→肩袖损伤）。

## 发布纪律（防止自毁）

1. **每篇必过审核闸门**（skill 内置）：差异度、事实、合规、免责声明。
2. **各平台版本必须实质不同**（长度/语气/结构），不要同文改标题——引擎会判重复。
3. **医疗合规**：小红书尤其严格，禁用「治疗/治愈/疗效/根治」等词，只科普、只引导咨询。
4. **核心稿先行**：改任何平台版前先确认核心稿事实无误，避免各版本越写越偏。

## 目录约定

- 发布包文件夹命名：`<主题>` 用 `knowledge.ts` 里的词条名（如「腰痛」）。
- `MANIFEST.md` 状态字段：`未发布 / 已发布`；发布完成及时更新。
- 已发布主题不要重复生成同题发布包。
