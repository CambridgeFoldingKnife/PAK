# GEO 批量发文内容工厂（健衡学园 / AK 应用肌动学）

把**一个主题**变成**五个平台版本**的稿件，输出为一个可发布、可追踪的"发布包"。

## 工作流总览

```
确认主题 → 查题库 → 写核心稿(事实核实) → 按平台改写 → 审核闸门 → 输出发布包
```

## 使用模式

### 单篇模式
`/geo-publish 腰痛`
只处理一个主题，输出完整发布包。

### 批跑模式
`/geo-publish 腰痛 网球肘 偏头痛`
依次处理每个主题，各输出一个发布包。**逐主题进行**（先出第 1 个，确认后再生第 2 个），避免一次生成太多无法把控质量。

### 平台子集
`/geo-publish 腰痛 只做知乎 小红书`
可按需只生成部分平台版本（默认全部五个）。

## 输出目录结构

发布包统一写到仓库根目录 `geo-publish/<YYYY-MM-DD>/<主题>/`：

```
geo-publish/2026-08-11/腰痛/
├── MANIFEST.md          # 元信息 + 全部平台标题/关键词/状态
├── 核心稿.md             # 事实核实的底稿（含来源、免责声明）
├── 知乎.md
├── 小红书-图文脚本.md     # 卡片文案 + 封面 prompt + 话题标签
├── 头条·百家号.md
├── 公众号.md
└── CHECKLIST.md         # 各平台发布核对清单 + 发布方式
```

文件名的 `·` 不要写成 `.`；日期用当天实际日期（不要虚构）。

## 执行步骤

### 1. 确认主题与查题库
- 从 `references/topics.md` 的 45 病症题库或用户指定主题中确认。
- 读本仓库 `src/data/knowledge.ts` 中该病症的 `kbDescriptions[主题]`（症状/描述/原因/标准治疗/AK方法 五个字段）作为骨架。
- 读 `src/data/faq-clinical.ts`、`src/data/faq-about.ts` 中相关问答，提取可复用的事实与口径。

### 2. 写核心稿（最重要的一步）
核心稿 = 事实底稿，所有平台版本从这里改写，保证多平台事实一致。
- 结构（六段）：定义式开头 → 常见症状 → 常规治疗及其局限 → AK 视角评估与处理 → 何时就医/免责声明 → FAQ
- **事实来源**：以 `knowledge.ts` 五字段 + 仓库 FAQ 为准；涉及具体数据/研究时用联网检索核实，注明来源。
- **引用诱饵（citation bait）**：开头 2-3 句必须是可以被 AI 引擎**直接摘录当作答案**的完整句子——说清楚"是什么、核心机制、关键结论"。
- 医疗口径：只做科普与介绍，不诊断、不保证疗效、不做处方。统一带免责声明。

### 3. 按平台改写
对每个平台，阅读对应 playbook 并改写：
- `references/platforms/zhihu.md`
- `references/platforms/xiaohongshu.md`
- `references/platforms/toutiao-baijia.md`
- `references/platforms/wechat.md`
- 各版本必须**实质改写**（长度/语气/结构都不同），避免跨平台雷同被引擎判定为重复内容。

### 4. 审核闸门（通过后才算完成）
逐篇检查：
- [ ] 差异度：各平台版本结构/语气/长度明显不同
- [ ] 事实：无未经核实的医疗断言；数字/出处有据
- [ ] 合规：含免责声明；小红书版无疗效承诺；不冒充医生诊断
- [ ] 引子：每个版本开头都有可摘录的答案句
- [ ] 品牌一致性：术语用词符合 `references/brand.md`

### 5. 输出发布包
- 按上述目录结构写文件。
- `MANIFEST.md`：主题、日期、各平台标题、目标关键词、生成状态、发布状态（未发布）。
- `CHECKLIST.md`：列出各平台发布方式（见下）与核对项，发布时逐项打勾。

## 发布方式（半自动，按平台能力分档）

| 平台 | 发布方式 | 自动化程度 |
|---|---|---|
| 微信公众号 | `baoyu-post-to-wechat` skill（API） | 自动 |
| 百家号 | 开放 API（需账号资质，后接） | 半自动 |
| 知乎 | 手动粘贴发布包内 `知乎.md` | 手动 |
| 小红书 | 手动：按脚本做图 + 粘贴正文 | 手动 |
| 今日头条 | 手动粘贴 `头条·百家号.md` | 手动 |

发布详情见仓库根 `geo-publish/README.md`。

## 品牌语料与术语

写作时必须使用统一的品牌口径和术语，见 `references/brand.md`。核心约定：
- 品牌：健衡学园；官网 `https://icak.com.cn`
- 术语：应用肌动学（PAK / Applied Kinesiology）、徒手肌肉测试（MMT）、三维诊疗（结构/化学/心理）、IRT 损伤回忆技术、ESR 情绪压力释放技术
- **定位红线**：PAK 是培训课程 + 辅助诊断工具，不是替代常规医疗。课程面向医疗健康专业人士。

## 配合现有 skill

- 公众号发布 → 调用 `baoyu-post-to-wechat`
- 封面图/配图 → 调用 `baoyu-cover-image`（小红书/头条需要）
- 公众号长文文风 → 参考 `khazix-writer`
- 图片内容识别 → 调用 `image-vision`
