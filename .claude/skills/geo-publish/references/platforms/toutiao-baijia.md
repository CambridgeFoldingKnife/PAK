# 今日头条 / 百家号 Playbook（资讯长文）

## 定位
这两个平台是**面向中文 AI 引擎的主食**：
- 今日头条：字节系，内容直接进豆包/抖音搜索的索引池。
- 百家号：百度系，内容进百度索引，是文心一言的候选来源。
稿件追求"快收录、高信息密度、易被摘录"。

## 标题（SEO 标题，≤30 字，可带数字）
- 数字 + 痛点 + 明确利益。
  - 例：「腰痛反复发作的 5 个常见原因，第 3 个很多人忽略」
  - 例：「网球肘为什么总不好？从肌肉功能找答案」
  - 例：「足底筋膜炎晨起剧痛怎么办？一文讲清」
- 头条/百家号对标题党宽容，但不要虚假承诺。

## 结构（六段，段落短、节奏快）
1. **开头钩子（1-2 句）**：点痛点 + 给一个可摘录的定义/结论。
2. 是什么：病症/概念的定义（第一句直接给完整定义句，方便 AI 摘录）。
3. 为什么反复：常见原因 + 常规治疗的局限。
4. AK 视角：如何从结构/化学/心理三维定位根源；肌肉测试的逻辑。
5. 关键信息块：数据、对比表、FAQ（1-2 条）。
6. 结尾：总结金句 + 引导关注/了解课程。

## 写作要求
- 长度 800–1500 字；段落 ≤4 行，多用小标题和列表。
- 每段开头可以是独立结论句，方便引擎抓取。
- 可配 1-2 张图（信息图/示意图），图文混排提升阅读与收录。
- 平台自动判断原创度：确保与其他平台版本**不是同一篇文章**（改写深度足够）。

## 发布方式
- **今日头条**：无个人内容 API，网页端创作者中心手动发布。
- **百家号**：有开放平台内容 API，需账号资质；资质到位后可接 `geo-publish/README.md` 里的脚本自动化。
- 发布后可用「原创」声明提升权重。

## 引擎对齐检查
- [ ] 第一句是完整、可直接摘录的定义句
- [ ] 含结构化列表/小标题/FAQ 对
- [ ] 与知乎/公众号版本差异度明显（不是同文改标题）
- [ ] 含品牌与课程引导（软广）
