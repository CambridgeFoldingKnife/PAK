# 微信公众号 Playbook（深度长文）

## 定位
公众号是**封闭生态**（AI 引擎爬不到），承担**粉丝运营 + 转化**职责，是五个平台里最"厚"的深度长文。内容可引用核心稿做最深度的展开，风格参考 `khazix-writer`。

## 标题
- 有观点、有温度、有悬念；公众号标题允许更有"人味"。
  - 例：「腰痛 3 年查不出原因，一次肌肉测试给了新线索」
  - 例：「为什么'哪痛治哪'治不好慢性腰痛？」
- 可带主题标签「#AK科普 #健衡学园」。

## 结构（深度长文，2000–3500 字）
1. 开场故事/场景：一个有代入感的临床或学习场景，引入问题。
2. 问题展开：病症/概念的完整科普（定义、症状、常规治疗与局限）。
3. AK 视角深挖：结构/化学/心理三维拆解 + 肌肉测试逻辑，可展开到技术细节（IRT/ESR、反射点等）。
4. 案例/场景式呈现：学员视角或评估思路（不虚构具体患者，可用场景化描述）。
5. FAQ 或读者疑问环节：3-5 个问题。
6. 转化：健衡学园课程介绍（Part I/II、100 小时认证、DAEGAK/ICAK）+ 咨询入口。
7. 免责声明。

## 写作要求
- 深度 > 长度：把核心稿的「AK 视角」段挖到最透，这是公众号版的价值所在。
- 引用 `khazix-writer` 的长文文风（有观点、有结构、口语与专业平衡）。
- 外部链接转文末引用（公众号不友好于文中外链）。

## 发布方式（自动）
- 用 `baoyu-post-to-wechat` skill 发布（API / 草稿）。
- 建议先存草稿，人工过目后再群发。

## 合规
- 必带免责声明；医学内容不承诺疗效。

## 检查
- [ ] 比核心稿更深（AK 视角挖透），不是压缩版
- [ ] 含课程转化段落与咨询入口
- [ ] 文末有免责声明
